# App Web Demo

Demo web separada para presentar la propuesta visual de venta de piso sin backend ni lógica real.

## Abrir

Opción simple:

```bash
open /Users/chimino/Desktop/lasuriana/app-web/index.html
```

O con servidor estático:

```bash
cd /Users/chimino/Desktop/lasuriana/app-web
python3 -m http.server 8085
```

Luego abre `http://127.0.0.1:8085`.

## Incluye

- Login mock
- Dashboard Home
- Vista Pedido
- Vista Inventario
- Navegación lateral para demo comercial

## Notas

- No usa backend
- No usa autenticación real
- No crea pedidos reales
- Usa datos mock solo para presentación
